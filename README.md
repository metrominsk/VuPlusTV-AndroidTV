# Vu+ TV: Android TV / Google TV (v0.5.2)

Клиент для просмотра эфира с ресивера Vu+ (Enigma2) на Android TV. Kotlin, Jetpack Compose, Media3.

## Сборка
1. Android Studio (Ladybug или новее) с Android SDK 35 и JDK 17+.
2. Откройте папку проекта, дождитесь Gradle Sync. Gradle 8.13 скачается по `gradle/wrapper/gradle-wrapper.properties`.

## Выбор плеера (если канал идёт рывками)
Во время просмотра удерживайте OK, в меню строка «Плеер» переключает плееры по кругу сразу, без выхода. Постоянный выбор также доступен в настройках:
- **ExoPlayer** (по умолчанию): аппаратное декодирование, увеличенный буфер, настройки разбора MPEG-TS.
- **VLC**: собственный декодер. Помогает, когда у ExoPlayer рывки, нет звука (MP2) или проблемный поток.
- **Системный**: штатный плеер приставки (MediaPlayer), на некоторых приставках работает лучше всего.
Сначала проверьте проблемный канал во всех трёх: набор кодеков зависит от приставки.

## Приставка не должна засыпать
Во время просмотра включаются флаг «не гасить экран», блокировка процессора и режим Wi-Fi без энергосбережения (нужны разрешения WAKE_LOCK и ACCESS_WIFI_STATE, они уже в манифесте).

## Первый запуск
Ресивер и ТВ в одной сети, на ресивере включён WebInterface (OpenWebif). При первом запуске откроются настройки:
IP-адрес, HTTP-порт (обычно 80), порт потока (обычно 8001), логин и пароль, если они заданы.

## Управление
| Где | Кнопка | Действие |
|---|---|---|
| Главный экран | D-pad, OK | выбрать канал; сверху ряд букетов, «Обновить», «Настройки» |
| Просмотр | ↑ / ↓ | предыдущий / следующий канал (также CH+/CH−, Media Next/Prev) |
| Просмотр | 0–9 | набрать номер канала, переключение через 2 секунды |
| Просмотр | OK | показать информацию о передаче (или повторить, если канал не открылся) |
| Просмотр | ← | панель каналов |
| Просмотр | → или Info | описание передачи и ближайшие передачи |
| Просмотр | удерживать OK (или Menu, если есть на пульте) | меню: смена плеера, каналы, описание, настройки |
| Везде | Back | назад; на главном экране выход |

## Что изменилось по сравнению со стартовым проектом
Исправления:
- Список каналов брался из `/web/getservices` без букета. Так возвращаются **букеты**, а не каналы. Теперь сначала загружаются букеты, затем каналы выбранного букета; папки и маркеры отфильтровываются.
- Видеопоток шёл на HTTP-порт интерфейса. Поток Enigma2 отдаёт на отдельном порту (по умолчанию 8001), он вынесен в настройки. Логин и пароль передаются и в запросы потока.
- Время передач показывалось как сырой Unix-timestamp. Теперь `ЧЧ:ММ–ЧЧ:ММ` и полоса прогресса.
- EPG запрашивался отдельным запросом на каждый канал, последовательно. Теперь два запроса на весь букет и обновление раз в минуту.
- Гонка при быстром переключении: поздний ответ EPG мог перезаписать выбранный канал.
- Звук продолжал играть при возврате на главный экран и при сворачивании приложения.
- `Text` в Material3 без `Surface` берёт чёрный цвет по умолчанию, то есть на тёмном фоне заголовки были бы нечитаемы. Добавлен корневой `Surface`.
- Не было `android:banner`, а без него приложение может не появиться в лаунчере Android TV. Добавлены баннер и иконка.
- `runCatching` вокруг suspend-вызовов глотал отмену корутин.
- XML разбирался регулярками, теперь DOM-парсером с очисткой недопустимых символов.
- Отсутствовал Gradle wrapper, не был задан `jvmTarget`.

Удобство:
- Видимый фокус на всех элементах (подсветка и увеличение): на ТВ без этого не понять, где курсор.
- Ленивая сетка каналов вместо одного горизонтального ряда со всеми каналами сразу.
- Фокус при открытии главного экрана и панели каналов сразу на текущем канале.
- Букеты, набор номера цифрами, экран ошибки с повтором, индикатор буферизации.
- Первый запуск ведёт в настройки, пароль скрыт, понятные тексты ошибок.
- Архитектура: ViewModel + StateFlow вместо 240 строк в одном файле.

## Что добавлено в 0.5
- Информационная панель по OK переделана в стиле инфобара ресивера: на всю ширину внизу. В шапке номер, название, дата, время с секундами и букет. Ниже пикон, текущая передача с полосой и «+N мин», следующая с длительностью и краткое описание.
- Из референса канала без запросов показываются SID/TSID/ONID и позиция спутника (с примерным названием). Названия спутников задаются в `data/ServiceRef.kt`.
- Уровень сигнала (SNR, AGC, BER) включается в настройках, по умолчанию выключен. Берётся запросом `/web/signal` раз в 2,5 секунды, только пока видна панель. Показания относятся к главному тюнеру ресивера, поэтому при включении приложение переключает сам ресивер на тот же канал (`/web/zap`). Не включайте, если ресивер одновременно смотрят на обычном телевизоре.
- Частота транспондера, поляризация и символьная скорость не показываются: из потока и референса их получить нельзя.

## Что добавлено в 0.4
- **Пиконы** возле каналов (сетка, список каналов, информационная панель). Берутся с ресивера по адресу `/picon/<референс>.png`, лежат в кэше на диске приставки, интернет не используется. Если пикона нет, показываются первые буквы названия. Чтобы пиконы появились, они должны быть установлены на ресивере.
- **Информационная панель** (OK во время просмотра): пикон, номер и название, передача, полоса эфира со временем начала, конца и «ещё N мин», краткое описание, следующая передача. Жёлтая строка: статус потока, видеокодек, разрешение, частота кадров. Зелёная строка: звуковой кодек, каналы (моно, стерео, 5.1), Dolby. Полное описание по кнопке «вправо».
- Сведения о потоке берутся из самого плеера, без дополнительных запросов. Полностью работают в ExoPlayer, в системном плеере доступно только разрешение, в VLC панель кодеков не показывается.
- При первом открытии канала приложение само переоткрывает поток до трёх раз, прежде чем показать ошибку (ресиверу нужно время на настройку тюнера).
- Панель информации держится 8 секунд.
- Убрана архитектура `x86_64` (эмулятор): APK стал легче.

## Ограничения
Проект запускался на реальном ресивере VU+ и приставка ТВ Xiaomi TV Box S 3rd Gen. Код написан по документации Compose, Media3 и OpenWebif, поэтому возможны мелкие ошибки компиляции. 
Некоторые каналы (например, HEVC или кодеки, которых нет в ТВ) могут не воспроизводиться.
Пароль хранится в обычных SharedPreferences, а HTTP идёт без шифрования: подходит только для домашней сети.
